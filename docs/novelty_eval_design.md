# 当前语义评估设计

1.0.0 的规范以[六个业务技能与独立评估](semantic-skills.md)为准：每个已完成技能独立检查术语与对象、结构与关系、逻辑与限定、语境与指称、功能与效果、评价与表达。

业务先生成带来源绑定的 `skill_records`，再冻结输出、读取可选独立参考并调用裁判。确定判断同时引用实际输出和原始依据，违反项给出反例与修订动作；证据不足或解释争议保留待裁决。不按标签是否相同或引用是否存在直接认定语义正确。

裁决为可接受、需修订、待裁决；执行未完成、调用失败单列。六维不加权、不累加，不输出分数、概率或通过率。技术数值、日期、单位和来源哈希仍保留。

使用 `tools/run_semantic_eval.py` 评估实际导出记录；使用 `tools/check_semantic_contract.py` 检查离线契约。后者和模拟响应测试均不能证明真实语义判断正确。

旧三框架评测和数值方案的原文见[整理前快照](history/pre-1.0.0/novelty_eval_design.md)，历史实现见[工程说明](../engineering/legacy/README.md)。
