# 2.2.0 本地 RSI 与 #8 评测整合

本版在已合并 #8 的代码上保留本地2.1.0执行链路，增加可选证据评分。正式业务和六维文字语义验收不变。

|方面|2.2.0 行为|
|---|---|
|测试材料|#8 公开材料在 `evals/testsets/`；用户材料在 `.local/testsets/`，互不混入|
|检索|本地模型规划查询、实际检索、取正文、逐篇核对；每次试跑重新执行|
|评分|融合#8逐目标/逐要素证据校验、相关性/日期/覆盖区分、错误分类；实际检索和候选F1分列|
|采纳|保留本地严格总分提高且各分项不退步；本轮重测保留版和候选版|
|锚集|保留本地选优完成后才读取独立案件锚集；#8池标签只留档|
|多模型|本版没有上游多模型盲测入口|

公开输入可增加 assessment_targets，私有参考可增加 evidence-v2 assessment；旧输入继续按 legacy-label-v1 执行。参见 [完整协议](../rsi-experiment.md)。
本版默认检索分和证据分各50%；v1.2手册的35/45/20仍有其独立含义，不被静默改写。

所有自动校验使用构造响应/原始夹具，不生成真实模型质量结论。用户标准、原件、案件及运行产物不进入Git提交。
