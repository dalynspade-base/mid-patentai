# 智慧芽检索和正文读取

在网页侧栏「检索平台」选「智慧芽」，确认发送检索词及使用额度。默认每条保留5个候选、最多读2篇正文。候选数量可选1–25；正文篇数另行限制。默认平台仍是 Google Patents；一次运行只向选中的平台发送检索词。

接入读取已有的 `patent-platform` MCP 配置（默认 `~/Downloads/mcp.json`）。文件在其他目录时，可在本地 `.env` 中把 `PATENT_PLATFORM_MCP_CONFIG` 设为绝对路径。只向既有 HTTPS 网关发送配置中的授权，不追随跳转。配置文件、授权及服务错误原文不写入报告。

可输入 `TACD:(压力传感器)` 等自定义智慧芽检索式。普通文字作为全文字段短语发送；留空时由原要素及已审核的同义词变体生成查询。每条只读取第一页，平台命中总数不代表本轮已读篇数或账号额度。搜索返回标题与公开号等元数据，通常没有摘要。

检索调用 P002。获取一篇正文最多调用三个平台工具：P012 著录项、权利要求读取（缓存、USPTO 或 P018）和说明书读取（缓存或 P019）。先核对同一公开号和智慧芽记录 ID，再读取文本。原文未取全或缺少公开日时保留为候选，记录失败；摘要和标题不作为全文证据。遇到[认证、额度、频率或服务暂停错误](https://open.zhihuiya.com/devportal/guides/rest-error-handling)，保留已获取内容并停止本批，等待明确重新运行。追加正文仍使用所选平台，并计入相应额度。

检索侧保留收到的正文，不按长度截断。后续模型复核仍遵守项目现有的单篇输入5万字符限制（包括要素、段落和出处等附加信息）。

程序入口：

```python
from modules.harness import NoveltyHarness

# 显式选择智慧芽会调用计费工具；示例只检索一次、最多读取一篇。
state = NoveltyHarness(search_provider="patsnap", results_per_query=5, max_documents=1).run(
    feature_text="压力传感器", query="TACD:(压力传感器)", cutoff="2026-11-09"
)
```

RSI 仍使用原有 Google Patents 数据源，以免改变历史实验对比口径。
