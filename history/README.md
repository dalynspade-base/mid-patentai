# 历史归档

当前业务入口在根目录README；本目录保存旧材料及仍需回归的兼容实现。旧文件按原来源保留，不把历史Google快照改称智慧芽，不把旧工程结果改称真实语义Eval。

| 目录 | 内容 |
|---|---|
| `docs/README-v2.5.0.md` | 本轮整理前的项目入口 |
| `docs/releases/`、`docs/pre-1.0.0/` | 历史发布及早期设计 |
| `reports/` | 旧报告、说明材料、安装及测试输出 |
| `engineering/legacy/`、`evals/legacy/` | 历史离线实现和固定夹具；当前兼容测试显式引用 |
| `tests/legacy/` | 历史工程回归，单独统计 |
| `tools/` | 旧诊断及历史运行入口；当前业务不调用Google检索 |
| `local/` | 本机旧运行、旧数据集、备份、原交接ZIP及整理清单；Git忽略 |

原 `.local/cases/`、凭据、虚拟环境和当前配置继续放在原位置。`evals/testsets/` 及 `modules/` 中仍被当前调用的快照兼容代码保留在当前源码树，避免移动造成执行断链。旧文档里的运行路径属于当时上下文，当前命令以根README为准。
