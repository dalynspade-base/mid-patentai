# 历史报告索引

本目录既有文件保留原字节，属于对应日期的历史结果，不是 1.0.0 语义验收。新运行保存到 `.local/` 下的新目录，不覆盖这些文件。

| 文件或目录 | 含义与边界 |
|---|---|
| basic_eval.json、unittest.txt | 早期合成工程回归，非专业语义正确率 |
| dependency_check.txt、dependency_install.txt | 早期安装环境记录，非当前环境证明 |
| implementation_manifest.json | 早期部署清单；所列旧文件不代表现行架构 |
| live_google_smoke.json | 2026-10-19 的公开页面连通性记录 |
| engineering_trial/ | 早期固定公开专利、来源快照与模型候选试验，保留当时边界 |
| harness_briefing_20261022/（本地如有） | 中期汇报文档与HTML，按文档内标注理解历史来源和结果 |

版本背景见 CHANGELOG.md，1.0.0 当前规范见 docs/semantic-skills.md。历史路径和旧命令保留其当时含义，当前操作以 README.md 为准。
