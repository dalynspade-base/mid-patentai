# 报告交付

使用 `skills.report_delivery_skill.run` 生成 JSON 和 Markdown；案件保存仍用 `modules.material_cases.save_result`，新结果另存，不覆盖原件或历史记录。

同时核对最终业务JSON与正文的含义，记录基准日、来源范围、目标版本、引用路径、修改前后摘要及未知。仅对选定目标交付结论，不将从属项、某个分支或修改版的结论扩展到整件申请；历史未记录的上下文不得补造。合同见[上下文协议](../../../docs/skill-contexts.md)。

逐项保持输入含义与证据推导。模型不改称人工，未找到不扩写成不存在，风险预筛不扩大为侵权或可授权判断。保存成功不等于完成专业评估。

报告包括六个业务技能的实际执行记录；独立评估仅附加与当前输出绑定相符的结果，不把旧裁决移到新输入。业务记录与评估意见分别保存，避免评估自身进入待评正文形成循环。

交付由独立裁判检查[六个语义维度](../../../docs/semantic-skills.md)，尤其关注限定、语境、评价表达与结论边界。

## 案件交付

案件结果保存在 `results/run-唯一时间戳/`，原始输入和旧结果不覆盖。网页“保存本轮结果到案件”使用 `modules.material_cases.save_result`，记录的是报告已保存，不冒称 AI、人工或专业评估已完成。合成回归通过不等于实际专利正确率；不保证授权，不输出侵权结论。
