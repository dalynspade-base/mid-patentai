# 候选检索

## 上下文

- 当前要素、基准日与来源范围
- 实际查询、扩展来源、获取失败和未读记录

共享本轮基准日、CN 新颖性与本轮来源范围、完整限定、目标版本/引用路径和真实上游记录；缺口保留未知。[共享协议](../../../docs/skill-contexts.md)按需读取。

## 核验

查询是否表达关键关系；同名提及与相关披露分开，元数据线索与正文分开；说明实际范围，不推定全网覆盖。

## 边界

返回候选不证明已披露；未找到、未读取或失败不证明不存在。

## 执行与交付

用 `modules.patent_tools.search_candidates` 检索智慧芽 或接收显式原文快照。保存实际查询、失败及未读范围；显式空快照不触发网络。背景中真实技术描述可以相关，广告或同名提及不自动相关。排序仅安排阅读。查询策略见[检索协议](../../../docs/search-evidence.md)。

由工具保留实际输入/输出、出处和执行状态；Python 函数调用不等于模型已经阅读材料。交给下游时传递限定、未知、范围和来源。独立验收按 [六维规范](../../../docs/semantic-skills.md)，不自行评分或补造参考。

## 智慧芽查询交接

读取上游短概念、已批准等义表达及完整目标。采用概念内OR、概念间AND的有界查询，原词先检索，再做扩展及单概念聚焦回退。各要素共享固定预算，独立查询轮流融合；保留真实下发式、候选编号、平台返回、融合排序、正文获取和公开日资格。没有可用锚点的长目标退回术语扩展，不拼碎长句。

平台总命中数、保存的返回数、前25文献、合格正文及已知参考覆盖是不同数量；空结果、接口失败和未读正文分别记录。公开/授权版本只在明确映射后合并，同一申请不冒称多个独立样本。金标可达性排查仅在隔离诊断侧执行，正式检索不读取金标。见[智慧芽协议](../../../docs/patsnap-search.md)。
