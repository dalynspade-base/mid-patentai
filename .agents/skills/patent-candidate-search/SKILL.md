# 候选检索

使用 `skills.candidate_search_skill.run`。实际查询、失败、未查要素、未读正文和来源快照分别保存；显式快照输入保持离线，不冒充新的在线检索。

输入须包含当前完整限定、关系、基准日、来源范围和查询变体的用途；交接 `patent_context` 与真实上游记录绑定。保留文献公开日期和未读范围，可能抵触申请不按普通现有技术直接确认；不以命中某份参考文献名单证明检索充分。详见[上下文协议](../../../docs/skill-contexts.md)。

先解释技术对象和关系，再判断标题摘要是否给出阅读线索。背景中实际描述的相关技术仍可有用，目录、广告、引用中的同名术语不自动构成技术支持。元数据判断不替代正文对照。

内部排序仅安排阅读，不生成新颖性概率；保留未知候选和来源。追加正文不覆盖已有快照或有效复核。

交付原文快照、查询与候选记录、范围和失败、绑定技能记录。由独立语义评估核验关键证据的相关性、遗漏与排序取舍，见[公共规范](../../../docs/semantic-skills.md)。

## 现有程序边界

实际检索按 `patent-candidate-search` 的实现和 Google Patents 范围；对话补查应明确范围，不混充程序执行轨迹。区分单篇完整披露、局部相似与跨装置近邻；不跨文献或互斥方案拼接。保留公开日期、种类码、版本、链接与原文位置，摘要只作线索。
