# 术语扩展

使用 `skills.synonym_expansion_skill.run`；可选模型候选用 `generate`。词典、新候选、明确审核及实际查询记录分开。模型候选不能自行批准。

读取完整要素关系、发明描述、已知领域及专门定义，将候选放回原句判断含义；缺少足以确定等义的语境就保留未知。接受并传递同一 `patent_context`，只改变查询表达，不改写目标限定；版本或基准日改变后重建绑定。专用合同见[上下文协议](../../../docs/skill-contexts.md)。

区分等义、上位、下位、相关、未知；后四类不能在当前同义替换通道冒充等义。保护专名、否定、条件、方向、单位、关系和步骤。查询有用不证明技术等义。

沿用理论/工程策略及查询预算；新增词只用于审核通过的查询，不自动写入证据归一化表或法律判断。

交付原词、候选词、语境、关系理由、处理状态、查询变体及绑定执行记录。

交独立 `patent-semantic-eval` 核验[六个语义维度](../../../docs/semantic-skills.md)，比较具体保真与漂移，不计算召回率、精确率或通过率。
