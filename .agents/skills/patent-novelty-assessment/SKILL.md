# 新颖性判断

## 上下文

- 目标版本和完整限定集
- 有效逐项复核、日期链与检索缺口
- 法域、任务及适用规则说明

共享本轮基准日、CN/Google Patents 范围、完整限定、目标版本/引用路径和真实上游记录；缺口保留未知。[共享协议](../../../docs/skill-contexts.md)按需读取。

## 核验

核验单篇文献同一披露方案是否支持完整目标；分支分别判断；检查证据资格、范围及未知，不以相同功能补足结构。

## 边界

仅新颖性预筛；创造性、公开充分性、支持、超范围等底线分别提示，不替代新颖性或承诺授权。

## 执行与交付

用 `modules.patent_tools.assess_precheck` 执行可核验的新颖性规则。基准日、范围或上游绑定冲突则退回重建。保留单篇完整披露风险、本次未发现完整披露、证据不足、超出范围四种结果；未发现不推出可授权，证据充分时也不能泛泛拒答。同类争议先比较关系、限定和证据条件，其他法律问题单独提示。

由工具保留实际输入/输出、出处和执行状态；Python 函数调用不等于模型已经阅读材料。交给下游时传递限定、未知、范围和来源。独立验收按 [六维规范](../../../docs/semantic-skills.md)，不自行评分或补造参考。
