# 独立语义评估

使用 `skills.semantic_eval_skill.run(records, client, confirmed, references)`。先冻结业务输出，再读取参考并单独调用裁判；不得以待测输出自行生成参考答案。独立表示评估阶段分离，不声称配置了另一模型或独立专家。

维度固定为术语与对象、结构与关系、逻辑与限定、语境与指称、功能与效果、评价与表达。逐维度说明满足、违反、未确定或有理由不适用；必需维度不能跳过。

按[各skill上下文合同](../../../docs/skill-contexts.md)核验实际职责，不能用同一泛化问题替代。先按语义返回 `activated_dimensions`：存在功能/结果限定、机制或效果主张时必须检查功能与效果；未提供上下文不等于不适用。显式 `semantic_focus` 也是必查下限。

六步完成后另作跨skill衔接核验：限定、版本、基准日、范围、未知与证据身份是否保持，报告是否放大结论；不是新增业务skill。各步正确但衔接错误，整体仍需修订。原文不足以验收才待裁决，正确表达“证据不足”的业务输出可以接受。同类案例只作有出处的模式参考，不自动决定当前申请不过审。

同时回查原始依据与实际输出。发现错误给具体反例/缺口及修订建议；材料充分而泛泛拒答也需修订。标签相同但证据链错误应拒绝，不因措辞不同否认有效解释。

仅给可接受、需修订、待裁决；执行未完成或失败单列，不生成完整验收结论。禁止分数、相似度、概率、权重、通过率或高中低评级。温度等技术数值仍保留。

参考可选，但来源、作者和绑定必须真实；没有独立参考时明确标记 none，不冒称专业金标准。输入或输出变化后旧裁决失效；不得靠回放旧输出评价新提示词。

契约自测与真实语义运行分开；伪造引文、遗漏维度、引文真实但不支持、标签正确但理由错误、合理拒答与过度拒答均需覆盖。详见[公共规范](../../../docs/semantic-skills.md)。
